# The World in One Day — 23 November 2026

A newspaper front page summing up Monday 23 November 2026: the COP31
climate talks collapse in Antalya and Monday's fallout, India six
wickets from victory in the Wellington Test, Nepal PM Balendra Shah's
talks with Narendra Modi in Delhi — plus the weekend's other big
stories (the Gulf war widening, the Kyiv drone strike, Verstappen's
Las Vegas win).

Entry for the make.fun bounty [Sum up 23 November's world news in one image](https://make.fun/bounty/news-image-20261123) — $100, 50 places.

## How it works

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).
The image itself was drawn with PIL; the repo ships the finished image.

## Run

```sh
python3 main.py
```
